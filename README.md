# Pokémon UNITE 全技能組一勝挑戰 V13

## V13 更新內容
- 防禦型角色卡片改為綠色系。
- 敏捷型角色卡片改為藍色系。
- 新增全角色挑戰進度總覽：整體完成率、五種定位的角色完成數及技能組勝場。
- 新增尚未完成技能組清單，點擊角色即可開啟該角色紀錄。
- 新增 OBS 實況模式：點擊網站「OBS 實況模式」按鈕會開啟獨立統計畫面，可作為 OBS 瀏覽器來源。
- 保留五種定位搜尋、角色名稱搜尋、隨機挑戰、JSON 匯入匯出與本機自動儲存。
- 不包含雲端同步功能。

## OBS 使用方式
1. 在一般網站頁面點擊「OBS 實況模式」，會開啟獨立視窗。
2. 在 OBS 新增「瀏覽器」來源，網址填入 `https://barro0625.github.io/unite-all-moves-tracker/?mode=overlay`。
3. 建議寬度 900、高度 320。OBS 瀏覽器來源需與控制頁使用相同瀏覽器環境及本機儲存資料；若 OBS 的瀏覽器來源無法讀取控制頁的 localStorage，請使用彈出的獨立視窗擷取或先測試資料更新情況。
4. 畫面每兩秒重新讀取本機紀錄，顯示已取得勝利、剩餘技能組、完成角色及完成率。
