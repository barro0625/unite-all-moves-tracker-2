# 備份安全更新版

## 本次新增
- 首次使用時顯示本機紀錄備份提醒，可選擇立即匯出或關閉提醒。
- 提供兩種匯出方式：「匯出備份（自訂檔名）」可自行輸入檔名；「快速備份（自動命名）」會自動加入日期與時間。
- 匯入前的安全備份及首次使用提醒使用快速備份，不會打斷流程要求手動輸入檔名。
- 顯示上次匯出備份的日期與時間。
- 匯入前先解析並驗證 JSON 結構、技能欄位、勝利紀錄及檔案大小。
- 通過驗證後，匯入前會先自動下載目前紀錄備份，再提示使用者確認匯入。
- 匯入採先寫入儲存空間、成功後才更新畫面的方式；格式錯誤、下載備份失敗或儲存失敗時，不會覆蓋目前資料。
- 保留原本 localStorage 儲存鍵與挑戰資料格式。

## 備份注意事項
挑戰紀錄仍儲存在目前瀏覽器的 localStorage。備份檔請保存到安全的位置；匯入前會先另行下載目前紀錄，但使用者仍應定期將備份複製到其他安全位置。


## 匯出方式說明
- **匯出備份（自訂檔名）**：跳出檔名輸入視窗，可輸入自己的檔名；副檔名 `.json` 會自動補上。
- **快速備份（自動命名）**：直接下載帶有日期與時間的 JSON 檔案。
- **匯入前安全備份**：使用快速備份產生 `pokemon-unite-before-import-backup_日期時間.json`，再套用通過驗證的匯入資料。
- 上次備份時間會由兩種匯出方式共用更新。

## Windows 桌面程式版（Electron）

此專案可透過 Electron 打包成 Windows x64 安裝程式。桌面版直接載入相同的 `index.html`、`style.css`、`app.js` 與 `pokemon.json`，原有 JSON 備份匯入／匯出功能可用於網站與桌面版之間搬移挑戰資料。

### 本機建置

1. 安裝 Node.js 20 或更新版本。
2. 在專案根目錄執行 `npm install`。
3. 執行 `npm run dist:win`。
4. 安裝檔會產生於 `dist/`。

### GitHub Actions 建置與網站下載入口

- Repository 的 Actions 頁面可手動執行 **Build Windows Installer**，取得 EXE Artifact。
- 若要發布到 Releases，推送 `desktop-v1.0.0` 形式的 tag，工作流程會建立 GitHub Release 並附上安裝檔。
- 網站側邊選單的「下載 Windows 桌面版」會連到 GitHub Releases 最新版本頁面。

### 資料移轉

1. 在網站使用「匯出備份」或「快速備份」，下載 JSON。
2. 安裝並開啟桌面版。
3. 在桌面版選單中選擇「匯入備份」，選取該 JSON。
4. 桌面版會依既有匯入流程驗證資料並在匯入前保護目前資料。

網站與桌面版的儲存空間彼此獨立，必須透過 JSON 備份移轉；不會自動同步。
