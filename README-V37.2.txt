# Pokémon UNITE Tracker V37.2

## 本版內容
- 以 V36 多語言網站及 Windows 桌面版為基礎。
- 將多語言招式名稱資料整合至 pokemon.json 的 moveNames 欄位。
- English / 日本語切換時，技能標籤會依目前語言顯示。
- 繁體中文原始技能名稱、技能組 ID、勝場紀錄與備份格式維持不變。
- 無可靠對應的項目會回退顯示繁體中文，不會自行拼造譯名。

## 翻譯資料說明
英文名稱沿用 V37 已有英文對照；日文名稱優先採用寶可夢系列常見正式招式名稱。這些名稱屬於暫用對照，未逐項由《Pokémon UNITE》現行遊戲畫面驗證。噴火龍試填項目依先前核對結果標記。請以遊戲內當前版本為最終依據。

## 主要檔案
- `pokemon.json`: 102 隻角色資料及多語言招式名稱。
- `app.js`: 技能顯示語言切換。
- `i18n.js`: 既有介面多語言。
- `electron/main.cjs` 與 `.github/workflows/build-windows.yml`: 沿用 V36 桌面版建置設定。

## 更新方式
解壓縮後，以本包完整檔案更新 GitHub 專案。若已有使用者資料，更新前先從網站或桌面版匯出 JSON 備份。


V37.3 技能名稱補齊
- 依使用者修改後的 CSV 作為唯一基準。
- 將原本以繁體中文代替的部分英文、日文名稱補齊。
- 保留使用者已經填寫的名稱，不覆蓋既有翻譯。
- 未能可靠對應的名稱維持原文並標記 needs-review。
- 更新 pokemon.json 的 moveNames，供英文／日文介面顯示使用。
