Pokémon UNITE Tracker 多語言介面檢查報告
網站內容版本：V37.5
Windows 桌面程式套件版本：1.0.2

一、主要問題與原因
1. 英文／日文切換時，render() 先把角色定位翻譯成顯示文字，再用繁體中文定位名稱查找 CSS class。翻譯後無法命中 class 對照，卡片失去 role-attacker / role-defender 等 class，因此定位底色與頂部識別色一併消失。
2. 淺色主題原本以純白背景覆蓋所有寶可夢卡片，造成五種定位色彩在淺色模式也無法辨識。

二、本次修正
- 角色定位 CSS class 一律使用 pokemon.json 的原始定位值產生；翻譯只用於畫面文字。
- 淺色主題新增五種對應的柔和定位底色。
- 修正固定流派名稱及招式在未完成清單、隨機挑戰結果中的多語言呈現。
- 修正英文初始啟動時，寶可夢英文名稱對照載入時序可能造成的回退顯示。
- 補齊新手導覽內容與小標籤的英文／日文。
- 補齊常見操作提示、備份確認、備份錯誤及驗證錯誤的語言顯示。
- 修正角色搜尋篩選器、排序器、選單按鈕、技能圖示與寶可夢圖片的無障礙標籤。
- 備份時間會依繁中、英文或日文介面使用對應日期格式。
- 保留武道熊師四個日文技能名稱。

三、資料與相容性
- pokemon.json 寶可夢：102 隻。
- movesets：102 組角色資料，無缺漏。
- 五種定位資料：攻擊型、防禦型、敏捷型、平衡型、輔助型。
- 不變更技能組 ID、勝利紀錄格式、localStorage key、Electron App ID。
- package.json 版本仍為 1.0.2；目前包裝預期是首次發布 1.0.2 的情境。
